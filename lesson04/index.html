✅ 魔法咒語已經偷偷複製好囉！
🎉 太棒了！你完成了一張魔法畫！
接下來跟著做，就能讓機器人幫你蓋出來～
1️⃣
打開 Minecraft 遊戲
2️⃣
打開 Code Builder（按 C 鍵，或點背包裡的小機器人）
3️⃣
把剛剛複製的「魔法咒語」貼進去
（Windows 按 Ctrl + V，Mac 按 Command + V）
4️⃣
按一下 執行 或 Run 按鈕
5️⃣
回到遊戲，按 T 打開聊天框，打上 build_art
6️⃣
按下 Enter 送出！🤖 機器人就會幫你蓋出魔法畫啦！
💡 小提醒：
· 機器人的背包要先清空，不然會蓋錯顏色喔！
· 站在空地上，四周留一點空間比較好蓋～
· 想再蓋一次，再打一次 build_art 就好啦！
